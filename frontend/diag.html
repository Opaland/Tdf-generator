Diagnostic des APIs externes

Vérifie la connectivité vers chaque service utilisé par le pipeline en mode réel. Si un service est injoignable, l'application reste utilisable en mode hors-ligne (ETAPEFORGE_OFFLINE=1 npm start) avec le simulateur.

    Consommation des quotas API

    Nombre de requêtes réellement envoyées à chaque service depuis le démarrage du serveur (compteur en mémoire, remis à zéro à chaque redémarrage — pas un historique persistant). Utile pour évaluer sa charge sur les API publiques gratuites lors d'un import ou d'une génération en lot.
