Diagnostic des APIs externes

Vérifie la connectivité vers chaque service utilisé par le pipeline en mode réel. Si un service est injoignable, l'application reste utilisable en mode hors-ligne (ETAPEFORGE_OFFLINE=1 npm start) avec le simulateur.

    Consommation des quotas API

    Nombre de requêtes réellement envoyées à chaque service depuis le démarrage du serveur (compteur en mémoire, remis à zéro à chaque redémarrage — pas un historique persistant). Utile pour évaluer sa charge sur les API publiques gratuites lors d'un import ou d'une génération en lot.

    Identifiants des connecteurs (Suunto, Strava)

    Provenance de chaque secret, jamais sa valeur. La base SQLite n'est pas chiffrée : un secret ou un jeton qui y est stocké est lisible par quiconque copie le fichier de base ou une sauvegarde automatique. Préférer les variables d'environnement pour les secrets d'application (voir docs/SYNOLOGY.md, « Identifiants des connecteurs »).

      Sauvegarde portable (export / import)

      Exporte les données produit (éditions, étapes, tracés, côtes…) dans un fichier JSON téléchargeable — pour déplacer ses données vers une autre installation, ou en garder une copie hors rotation. Complète la sauvegarde automatique de fichier (ETAPEFORGE_BACKUP_DIR, voir docs/SYNOLOGY.md) sans la remplacer : celle-ci sert la reprise après sinistre sur la même installation, celle-ci sert la portabilité. Le réimport remplace toutes les données produit existantes — pas de fusion.
